## One Switch 解决的是哪一类麻烦

One Switch 是 Fireball Studio 做的 macOS 菜单栏工具。点一下菜单栏图标，下拉一排开关，深色模式、保持唤醒、隐藏桌面图标、勿扰、夜览、连接 AirPods、清洁屏幕这些常用项默认就摆在那儿，一共九个。偏好设置里还能再开十多个，从台前调度、静音麦克风到清空废纸篓、改屏幕分辨率、清 Xcode 缓存都有。

每个开关都能单独绑快捷键，不用的可以藏起来，顺序也能拖。部分开关底下有二级面板，深色模式能设定时切换，屏幕分辨率会直接列出一串可选值，AirPods 那项还会显示电量。Softpedia 的评测提到，这套快捷键和自定义能力是它比其他菜单栏小工具更耐用的原因。

它解决的问题很具体：这些功能 macOS 本来就有，只是散在系统设置、控制中心或者终端命令里，改一次要点五六下。One Switch 把它们收进一个下拉菜单，代价是菜单栏常驻一个图标。

缺点说几个具体的。

它是个效率小工具，不是刚需。43 元买的是一天省下十几次点击，如果你一周都用不上一次深色模式切换，这钱花得没意义。

退款条款在商品页上没找到明确说明。数码荔枝的订单如果要退，最好在下单前先问清楚规则，别等激活之后再扯皮。
